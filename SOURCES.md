## Official syllabus used to organise the repository

- **Source:** [Exam AZ-900 study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/az-900)
- **Skills measured:** July 20, 2026
- **Exam weights:** Cloud concepts 25–30%; architecture/services 35–40%; management/governance 30–35%.
- **Supplemented topics:** Some exam objectives were absent or only briefly mentioned in the uploaded notes. They are labelled **Syllabus supplement**, especially Azure compute options, storage transfer tools, authentication methods, Azure Resource Manager and Service Health.

## Editorial rules

1. Preserve the original learning intent and keep definitions beginner-friendly.
2. Improve spelling, grammar, sentence flow and table formatting.
3. Consolidate repeated ideas into one clear explanation.
4. Where technical shorthand is misleading, correct it and explain the correction in the [corrections log](04-Exam-Preparation/corrections-log.md).
5. Do **not** present promotional discounts, student credit amounts, licensing rights or service availability as universal guarantees.
6. Treat extra examples and scenarios as instructional examples, not quotes from the uploaded PDFs.
7. When notes mention an adjacent subject outside the current outline, include it only as an optional sidebar.
